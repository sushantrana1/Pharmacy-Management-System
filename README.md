# 💊 MediStock - Pharmacy Inventory Management System

MediStock is a web-based Pharmacy Inventory Management System developed to simplify pharmacy operations such as medicine inventory management, sales, purchases, suppliers, employees, and customer records. The system helps pharmacies maintain accurate stock levels, prevent expired medicine sales, and generate sales reports efficiently.

---

### 🔐 Authentication
- Secure Admin Login
- Pharmacist Login
- Role-based access control

### 💊 Medicine Management
- Add, Edit, Delete Medicines

- Stock Quantity Management
- Remaining Stock Calculation
- Low Stock Alerts

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/medistock.git
```

### 2. Move Project

Copy the project folder into:

```
xampp/htdocs/
```

### 3. Start XAMPP

Start:

- Apache
- MySQL

### 4. Create Database

Open phpMyAdmin and create a database named:

```
medistock
```

Import the SQL file included in the project.

### 5. Run Project

Open your browser:

```
http://localhost/medistock
```
